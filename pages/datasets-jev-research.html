Dataset Blueprint

Where to test an embedding + Jev classifier when there are too many labels

Four candidate datasets, one clear first pick.

What we are looking for

The project pairs an embedding model with Jev, a hosted decision model that picks an answer from a list of options. Jev and its open cousin Laya both work by reading the options in the prompt, so a long list of labels is where they struggle. We want datasets that make that problem real.

More than 20 labelsEnough that listing every option strains a decision model. The more, the sharper the test.
Not overusedFewer prior results means a cleaner contribution and fewer reviewers who have seen it before.
Time mattersA setting where answering in milliseconds is a real requirement, so a fast pipeline has a story to tell.

The idea in one picture

Instead of handing Jev every label, let a fast embedding model do the first cut. Jev then only has to choose among a few survivors.

Query"Tell my bank I lost my card"
EmbedScore every label by similarity. Milliseconds.
ShortlistKeep the top k labels.
JevChoose among k options, return a probability.
AnswerOne label and its confidence.

Illustration only. It shows how much smaller Jev's choice becomes, and assumes the right label survived the first cut. Whether it does is exactly what the experiments would measure (shortlist recall at k).

The candidates

Best fit

CLINC150

150 customer intents. Short queries. Fast answers expected.

  • Labels150, plus out-of-scope
  • Sizeabout 23,700 queries
  • Inputone short sentence
  • Time-critical anglevoice assistants, routing
  • Popularitywell known
Strengths
  • Nearly double the 77 labels already tested
  • Short text keeps each Jev call quick
  • Related intents per domain make the shortlist step meaningful
Weaknesses
  • Fine-tuned models already score very high
  • Intents are fairly clean, so embeddings alone may do most of the work
Opportunities
  • Subsample to 10, 25, 50, 100, 150 labels for a scaling curve
  • Out-of-scope class tests abstention
Threats
  • Popular, so novelty rests on the method
  • Public data may inflate zero-shot scores

Verdict: the anchor dataset. Reviewers know it, and it stretches the label count.

GitHub Hugging Face Paper

MASSIVE

60 intents in 51 languages, including Indian languages.

  • Labels60 per language
  • Sizeabout 1M utterances
  • Time-critical anglevoice assistants
  • Popularitymoderate
Strengths
  • Same labels across many languages
  • Laya ships a multilingual model to compare against
Weaknesses
  • 60 labels is below what Jev already handles
  • Results spread across languages
Opportunities
  • Show embeddings rescue weaker languages
  • Cross-lingual transfer tests
Threats
  • Weak Jev results may reflect language coverage, not label count

Verdict: the second dataset, for the multilingual angle.

GitHub Hugging Face

WOS-46985

Scientific abstracts with 134 topics in two levels.

  • Labels134, hierarchical
  • Sizeabout 47,000 abstracts
  • Inputlong paragraph
  • Time-critical angleweak
  • Popularityniche
Strengths
  • Less used, so more novel
  • Hierarchy allows a two-step shortlist
Weaknesses
  • Long inputs raise Jev's cost and latency
  • Topics overlap heavily
Opportunities
  • Hierarchical shortlisting as a distinct contribution
Threats
  • Undercuts the speed story
  • Known label inconsistencies

Verdict: optional extension if you want a hierarchy.

Mendeley Data
High risk

CESNET-TLS22 / QUIC22

Encrypted network traffic sorted into about 190 web services.

  • Labelsabout 190 (TLS), about 100 (QUIC)
  • Inputnumeric flow features, not text
  • Time-critical anglestrong, traffic is live
  • Popularityrarely used
Strengths
  • Highest label count in the set
  • Speed genuinely matters
  • Novel pairing
Weaknesses
  • Features must be turned into text for Jev
  • Embeddings over numbers are not clearly better than a standard classifier
Opportunities
  • A strong claim if the text conversion works
Threats
  • A trained classifier on raw features will likely win, which makes the comparison look poor

Verdict: attempt only after CLINC150 and MASSIVE are done.
