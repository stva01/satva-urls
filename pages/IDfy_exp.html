IDfy Interview Experience

Online Assessment + 2 Technical Rounds

Online Assessment

One SQL question and four DSA questions.

SQL — Top Files by Month Count records per file and return the top 5 files logged in March, ordered by count descending.
DSA 1 — Cascading Shift Given a string (e.g. "ABC") and an array of integers (e.g. [1, 2, 3]), for each value k at position i, shift the first k characters of the string forward by one letter (cyclically, A→B, etc.). Apply the shifts in sequence and return the final string.
DSA 2 — Unique Values at Minimum Cost Given an array of values (e.g. [8, 9, 8]) and a parallel cost array (e.g. [1, 2, 3]), make all values unique by repeatedly incrementing duplicates by 1. Each increment costs the value at that index in the cost array. Minimize total cost — e.g. with duplicate 8s at index 0 (cost 1) and index 2 (cost 3), increment the cheaper one.
DSA 3 — Fill the Blanks Around a Substring Given a string containing wildcards (e.g. ??? D ?) and a target substring (e.g. "ABC"), place the substring so it fits fully within the wildcard positions at least once. Fill any remaining wildcards with the lexicographically smallest letter ('A').
DSA 4 — Sum of Absolute Differences per Query Given a price array (e.g. [1, 2, 3]) and a query array (e.g. [2, 3, 4]), for each query value compute the sum of its absolute difference with every price in the array, and return the list of these sums.

Round 1 — Projects & Fundamentals

Resume / Project Deep-Dive

  • Why Snowflake specifically for the project?
  • Snowflake vs. Postgres vs. Redis — when do you reach for each?
  • What is a data warehouse, and when do you actually need one?
  • What storage/file formats do these different databases use under the hood?

Security & Access Control

Since the project used an MCP-based tool to run SQL, the interviewer asked how access was controlled and how accidental data deletion was prevented.

OA Redemption

Asked to live-solve the DSA question missed in the online assessment.

Computer Networks

Web Services

  • REST API basics and HTTP methods
  • Can you create a new resource using PUT vs. PATCH?

Round 2 — Database & Architecture Design

This round was the toughest — the interviewer wasn't convinced by the existing data warehousing project and pushed into a grueling, iterative system design exercise.

Architecture Redesign

Asked to redesign the project architecture from scratch, with the interviewer suggesting alternatives like EC2 or a relational database instead of a data warehouse.

The Schema Design Loop

A repeating cycle:

  1. Propose a database schema
  2. Interviewer gives a specific SQL query to run against it
  3. If the schema can't support the query, redesign it
  4. Repeat

This loop repeated 14 times.
