Unit 1 — Introduction to Penetration Testing

Information Security & the CIA Triad

InfoSec is the practice of protecting information and systems from unauthorised access, disclosure, disruption, modification, or destruction. Every security control traces back to one of three pillars:

Confidentiality

Only authorised parties can view data. Enforced via encryption, ACLs, MFA. Violation example: data exfiltration, credential theft.

Integrity

Data stays accurate and unaltered. Enforced via hashing (SHA-256), digital signatures, checksums. Violation: SQL injection, file tampering.

Availability

Systems accessible when needed. Enforced via redundancy, failover, rate limiting. Violation: DoS/DDoS attacks.

Extra Pillars

Beyond CIA: Non-repudiation (actions traceable to source) and Authentication.

Ethical Hacking & the Five Phases

Ethical hacking is the authorised, legal practice of probing systems to find vulnerabilities before malicious attackers do. The distinguishing factor from black-hat hacking is permission and intent — not tools or techniques. All work must stay inside the Rules of Engagement (RoE); testing outside scope is illegal even with good intentions (violates laws like the CFAA).

VA answers: "What vulnerabilities exist?"  |  PT answers: "Can they actually be exploited, and what damage results?"

Why both matter: VA is a broad, low-cost, high-frequency check for known issues. PT is deep, expensive, and periodic — proving whether vulnerabilities (even chained low-severity ones) are actually exploitable. A mature program uses both.

Legal & Ethical Considerations

Testing without written authorisation is a criminal offense virtually everywhere. Verbal agreements are insufficient.

DocumentPurpose
Letter of Authorization (LoA)Single most critical document — grants legal permission to test
NDAConfidentiality agreement protecting both parties
Rules of Engagement (RoE)Defines scope, techniques, testing windows, escalation, stop conditions
Statement of Work (SoW)Commercial contract — deliverables, timeline, payment

Key laws: CFAA (USA, 1986), CMA (UK, 1990), IT Act 2000 (India — Sections 43 & 66), GDPR (EU, 2018), CCPA (USA, 2020).

"A client asks you to test X. You find a critical vuln on an out-of-scope server." → Never test out-of-scope systems. Notify the client's emergency contact per RoE, document the discovery, do not attempt exploitation.

Debian-based distro by Offensive Security, 600+ pre-installed tools, rolling release model. First released 2013 (derived from BackTrack). Default DE: XFCE (since 2019). FHS-compliant — tools in /usr/share/, /usr/bin/; wordlists in /usr/share/wordlists/.

Deployment: ISO, live boot, Docker, WSL2, ARM (Raspberry Pi), cloud AMIs (AWS/Azure).

Recon splits into two categories based on whether the tester directly interacts with the target's systems.

DetectabilityUndetectableMay be logged / trigger alerts

OSINT — Core Techniques

Search Engine Dorking

site:target.com filetype:pdf, intitle:"index of", inurl:admin. Google Hacking Database (GHDB) maintains thousands of dorks.

Social Media Intel

LinkedIn/Twitter/GitHub mining for employee names, job titles, tech stack, org structure.

Web Archive Analysis

Wayback Machine reveals deprecated endpoints, old login portals, removed sensitive files.

Email Harvesting

Collecting addresses to infer naming conventions (firstname.lastname@company.com) via theHarvester.

Certificate Transparency

crt.sh reveals all subdomains with issued SSL certs — reliable passive subdomain enum method.

Metadata Analysis

FOCA / ExifTool extract author names, software versions, internal file paths, GPS data from public documents.

Subdomain enumeration methods: Brute force (Gobuster, Sublist3r, Amass with wordlists), Certificate Transparency (crt.sh), DNS aggregators (DNSdumpster, SecurityTrails, VirusTotal).

DNS Zone Transfer

A Zone Transfer (AXFR query) is a legitimate mechanism to replicate DNS zone databases from primary to secondary DNS servers. When misconfigured, a DNS server responds to AXFR requests from any client — letting an attacker download the entire zone file in one request.

Impact: reveals every hostname/IP in the domain — internal hosts, staging servers, VPN gateways — equivalent to a full infrastructure map.

# dig
dig axfr @ns1.target.com target.com

# nslookup
nslookup -type=any target.com

# host
host -t axfr target.com ns1.target.com
Mitigation: Restrict AXFR to authorised secondary DNS server IPs only (ACL-based, supported in BIND/Windows DNS). Regularly audit configuration. Also: DNS split-horizon, DNSSEC to prevent spoofing/cache poisoning.

WHOIS Lookups

Query protocol for registered domain/IP resource owners. Reveals: registrant details (org, contact — may be privacy-protected), registration/expiry dates, name servers, registrar info, admin/technical contacts.

IP WHOIS via Regional Internet Registries: ARIN (N. America), RIPE NCC (Europe), APNIC (Asia-Pacific), AFRINIC (Africa), LACNIC (Latin America).

Unit 3 — Vulnerability Assessment & Analysis

What Is a Vulnerability?

A weakness or flaw in a system/app/network/process exploitable by a threat actor to gain unauthorised access, cause damage, or disrupt services. Arises from design flaws, coding errors, misconfigurations, or inadequate controls.

TermMeaning
VulnerabilityThe weakness itself (e.g., unpatched software)
ThreatThe potential cause of harm (e.g., a malicious attacker)
RiskLikelihood × Impact of a threat exploiting a vulnerability
ExploitThe actual technique/code used to take advantage of it

Types of vulnerabilities: Software (buffer overflows, injection, use-after-free), Configuration (insecure defaults, open ports, weak permissions), Network (unencrypted comms, poor segmentation), Human/Process (social engineering, weak password policy, poor patch management).

CVSS — Common Vulnerability Scoring System

Open industry standard scoring severity 0.0–10.0. Current: CVSS v3.1, with v4.0 emerging.

Base Score

Intrinsic, constant characteristics: Attack Vector (N/A/L/Physical), Attack Complexity, Privileges Required, User Interaction, Scope, CIA Impact.

Temporal Score

Adjusts for time-based factors: exploit code availability, remediation level, report confidence.

Environmental Score

Customises for the org's specific context: asset importance, existing controls.
Score RangeRatingAction
0.0NoneInformational only
0.1–3.9LowLow priority remediation
4.0–6.9MediumAddress in scheduled maintenance
7.0–8.9HighPrioritise urgently
9.0–10.0CriticalImmediate action required

Format: CVE-YEAR-NUMBER (e.g. CVE-2021-44228 = Log4Shell). New CVEs assigned by CNAs (CVE Numbering Authorities). NVD adds CVSS + CWE + CPE metadata on top of raw CVE entries. Exploit-DB categorises exploits by type: remote, local, DoS, webapps, shellcode; searchable offline via searchsploit.

The pipeline: CVE assigns an ID → NVD scores it (CVSS) → Exploit-DB provides the weaponised PoC used in the exploitation phase.

Automated Vulnerability Scanning

Systematically probes systems against known-vulnerability databases (CVE/NVD) to generate a findings list.

Strengths

Speed (hundreds of hosts in minutes), Coverage (thousands of CVEs checked simultaneously), Consistency (repeatable results), Reporting (structured output).

Limitations

False positives (version string ≠ patch status), False negatives (logic flaws, zero-days missed), Noise (huge data volume), Credentialed vs uncredentialed trade-offs, potential network disruption.
Automated scanning is a starting point, not a complete assessment — always supplement with manual testing.

Nessus (Tenable)

  • 170,000+ plugins, regularly updated for new CVEs.
  • Credentialed scanning (SSH for Linux, WMI/SMB for Windows) — checks patch levels, registry settings invisible to unauthenticated scans.
  • Compliance auditing: PCI-DSS, CIS Benchmarks, HIPAA, DISA STIG, ISO 27001.
  • Scan types: Basic Network Scan, Advanced Scan, Web Application Tests, Credentialed Patch Audit.
  • Reports in PDF, HTML, CSV, Nessus XML.

OpenVAS / GVM (Greenbone)

  • Fully open-source and free. Leading alternative to Nessus.
  • 50,000+ NVTs updated daily from Greenbone Community Feed.
  • Web interface: Greenbone Security Assistant (GSA).
  • Supports authenticated + unauthenticated scanning; XML/PDF reports; GMP API for SIEM integration.
  • Pre-installed in Kali Linux.

Web App Scanning — Nikto, OWASP ZAP, Burp Suite

Nikto

Tests 6,700+ dangerous files/programs, outdated software, header misconfig (HSTS/CSP), SSL weaknesses, dangerous HTTP methods. Intentionally noisy — no IDS evasion. Best as quick first-pass tool. 
nikto -h http://target.com
nikto -h https://target.com -ssl
nikto -h http://target.com -Tuning 9

OWASP ZAP

Free intercepting proxy. Spider/AJAX Spider crawls pages. Passive scan analyses traffic automatically. Active scan sends attack payloads (SQLi, XSS, CSRF) — authorised targets only. REST API for CI/CD.

Burp Suite

Industry-leading (PortSwigger). Proxy (intercept/modify), Repeater (manual replay), Intruder (fuzzing/brute force), Scanner (Pro-only auto detection), Decoder, Comparer.

ZAP Workflow

Configure browser proxy (127.0.0.1:8080) → Spider target → Passive scan (automatic) → Active scan → Review alerts → Generate report.

Vulnerability Prioritisation & Risk Assessment

Risk = Likelihood × Impact

Likelihood Factors

Attack Vector (Network vs Local), Attack Complexity, Privileges Required, exploit availability, active exploitation in the wild.

Impact Factors

Confidentiality/Integrity/Availability impact, business criticality of asset, regulatory implications (GDPR, PCI-DSS).
Likelihood \ ImpactVery LowLowHighVery High
Very HighMediumHighCriticalCritical
HighLowMediumHighCritical
MediumLowMediumMediumHigh
LowInfoLowLowMedium

Beyond CVSS alone, consider: Exploit Availability (public Metasploit/Exploit-DB module = much higher urgency), Asset Criticality (medium vuln on payment server > critical vuln on isolated dev box), Network Exposure (internet-facing >> internal/air-gapped).

CVE Case Studies

Log4Shell — CVE-2021-44228 10.0

RCE in Apache Log4j 2 (Java logging library). Unauthenticated attacker executes arbitrary code via a crafted string in any logged field (HTTP headers, usernames). Attack Vector: Network. Affected millions of systems globally — a supply-chain catastrophe. Scanners released plugins within 24 hours.

EternalBlue — CVE-2017-0144 8.1

SMBv1 RCE vulnerability, NSA-developed, leaked by Shadow Brokers (2017). Weaponised in WannaCry ransomware & NotPetya. Nessus plugin MS17-010 detects it. Key lesson: CVSS score (8.1, "High") did not capture the catastrophic real-world business impact — CVSS is a starting point, not the full risk picture.

Vulnerability Assessment Report Structure

  1. Executive Summary — non-technical overview for senior management
  2. Scope and Methodology — systems assessed, tools used, scan types, timeline, limitations
  3. Findings Summary — table of confirmed vulnerabilities by severity with counts
  4. Detailed Findings — CVE ID, CVSS, affected hosts, description, evidence, remediation per finding
  5. Remediation Recommendations — prioritised roadmap: short-term (patch now), medium-term (30 days), long-term (strategic)
